# 📚 Repositório de Estudos em Java e Tecnologias Relacionadas

Este repositório foi criado para **fins de estudo e prática**, abordando diversos tópicos do ecossistema Java e tecnologias complementares que são fundamentais para o desenvolvimento de software moderno.

## 🎯 Objetivo

Organizar o aprendizado em um **roadmap estruturado por pastas**, separando os conteúdos por temas e tópicos, facilitando o acompanhamento da evolução nos estudos.

---

## 🛠️ Estrutura do Roadmap

Cada tópico listado abaixo terá uma **pasta dedicada** com materiais, exemplos de código, anotações, e exercícios práticos.

---

### 📌 1. Java

- Interfaces
- Extensão de classes
- Iteração com for-each (lambda) e Streams
- Uso de Generics
- Boas práticas de equals/hashCode: essenciais para trabalhar corretamente com coleções.
- Testes unitários (JUnit)
- Interfaces da Collection API: List, Set, Map, Queue
- Uso de Comparator e Comparable para ordenação
- Manipulação de arquivos com File (ler, escrever, editar e apagar arquivos) - java.nio
- Serialização e JSON: uso de bibliotecas como Jackson ou Gson para leitura e escrita de JSON
- Gerenciamento de memória e Garbage Collector: noções básicas de heap, stack, objetos imutáveis
